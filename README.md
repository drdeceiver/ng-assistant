# Ordis Assistant

A personal, non-commercial desktop assistant for **The First Descendant**.

## What it does

- Reads the operator's **own** account data through the NEXON Open API
  (equipment, modules, progression, challenge records).
- Displays public game metadata (descendants, weapons, modules, reactors,
  external components, cores).
- Reads public leaderboard information.
- Helps the operator compare builds and plan which content to farm.

## How the data is used

- Data is consumed **locally, on the operator's own machine**, for personal reference only.
- Nothing is stored on a server.
- No data is redistributed, resold, or shared with third parties.
- Requests are made at most a few times per hour, well under the documented rate limits.

## Scope

- Single user (the operator).
- No accounts, no registration, no public hosting.
- Not affiliated with NEXON or the game's publisher.

## Notes

Game data and assets are the property of NEXON.
This project is a private tool, not a published service.
